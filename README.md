# Saumy Shah — Smart AI Portfolio

A modern, conversational portfolio designed around an AI-chat experience.

## Features

- AI-style portfolio assistant
- Quick-question chips
- Responsive light futuristic UI
- Selected projects section
- Skills/toolkit section
- Contact CTA
- GitHub integration
- Mobile-friendly layout

## Files

- `index.html` — portfolio structure
- `style.css` — complete UI and responsive styling
- `script.js` — interactive portfolio assistant

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Customize

Update the project cards, skills, contact email, GitHub link and AI responses in the three files.
